# FlightCompass

A flight strategy explorer for the cost-conscious traveler. Interactive world map showing
cheapest cached fares from any origin, with a recommendation engine that scores four
booking strategies side by side: cash, airline miles, ShopBack cashback, and VPN-
arbitraged currency.
Live demo: https://<username>.github.io/flightcompass/
What it does
Drill from world → continent → country → airport. At any airport you see:
Cheapest current cash price (sourced from Aviasales cache, refreshed weekly)
Best booking currency with native-currency savings via VPN
Saver award chart rate for the optimal miles program for that route
Top ShopBack cashback platforms for flights and hotels
Amex Platinum FHR eligibility flag for hotels in major cities
Trip cost optimizer — compares total cost (flight + hotel × nights) across the region,
surfaces if a different country offers a cheaper net trip
A recommendation engine that scores all four strategies and picks the winner with
specific guidance
What it isn’t
Not a booking tool. Use Skyscanner, Google Flights, or the airline website to actually
book.
Not financial advice. Strategy guidance based on publicly-known booking channels.
Not real-time. Aviasales’ cache lags by up to 7 days. Always verify prices on the airline
site before booking.
Not affiliated with Aviasales, ShopBack, Amex, or any of the booking platforms
referenced.
Why this exists
Most flight tools either show prices or show points redemptions. None compare the
strategies side by side and honestly say “for this route, cash + cashback beats burning your
miles, here’s the math.” This tool fills that gap. It’s a strategy explorer with the maths
exposed.
How it works
1. A GitHub Action runs every Tuesday 06:00 UTC, fetching cached flight prices from
Aviasales’ public price-map endpoint for a defined set of origins
2. The Action commits flight-data.json back to the repo
3. GitHub Pages serves the static site
4. The browser fetches the JSON same-origin (no CORS, no API keys, no failures)
5. Demo data is a silent fallback if the snapshot is missing
Hand-curated reference data:
Miles award charts for 10 major frequent flyer programs, by region and distance tier
ShopBack cashback rates (historical highs, May 2026)
Hotel nightly rate medians for ~100 major cities
Amex Platinum FHR eligibility list for major luxury markets
