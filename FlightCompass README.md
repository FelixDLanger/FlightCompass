# FlightCompass

A research-oriented flight strategy explorer. Interactive world map showing the cheapest cached fares from major hubs, with an analysis engine that scores booking strategies independently: cash, airline miles, OTA cashback, and currency-based pricing differences.

**Live demo:** `https://<username>.github.io/flightcompass/`

## What it is

A doctoral-research-adjacent decision tool. Drill from world → continent → country → airport. At each level you see:

- **Lowest cached cash price** from the Aviasales/Travelpayouts API (refreshed weekly via GitHub Action)
- **Cheapest booking currency** with the FX edge from booking in native currency
- **Saver award chart rate** for the optimal miles program, with explicit guidance to verify availability
- **Top ShopBack cashback platforms** for flights and hotels (historical reference rates)
- **Amex Platinum FHR eligibility** flag for hotels in major luxury markets
- **Trip cost optimizer** — compares total cost (flight + hotel × nights) across the region, surfaces if a different country offers a cheaper net trip
- **An analysis engine** that scores all strategies independently (each out of 100) and highlights the strongest fit per route

## What it isn’t

- **Not a booking platform.** Strategy guidance only — always book on the airline website, OTA, or trusted partner.
- **Not financial advice.** Informational tool to help compare publicly available booking channels.
- **Not real-time.** Aviasales’ cache lags by up to 7 days. Always verify prices on the airline site before booking.
- **Not affiliated** with Aviasales, ShopBack, Amex, or any booking platform referenced.

## Methodology

- **Flight prices**: sourced from the Travelpayouts/Aviasales Data API. Snapshot refreshed weekly via GitHub Action.
- **Award charts**: hand-curated reference data for 10 major frequent-flyer programs (KrisFlyer, Asia Miles, Qatar, Emirates, Flying Blue, Lufthansa M&M, BA Avios, United, ANA, Qantas) by region and distance tier.
- **Cashback rates**: hand-curated historical highs (May 2026) for ShopBack flight and hotel categories. Must be verified live before booking.
- **Hotel rates**: hand-curated median 4★ rates for ~100 major cities, used for trip-cost comparisons.
- **Amex FHR eligibility**: hand-curated list of major luxury markets typically listed in Amex Fine Hotels & Resorts.

## Strategy scoring

Each strategy receives an independent score (0-100). Scores do **not** sum to 100 — multiple strategies can apply simultaneously (e.g., book direct with airline AND stack cashback). The highest-scoring strategy is highlighted; users see all scores and decide.

Scoring inputs:

- **Cash/CCY**: native currency availability for the destination
- **Miles**: saver-rate value vs cash equivalent (sweet spot ≥ €1.40 per 1K points)
- **Cashback**: peak ShopBack rate for relevant platforms (peak ~6%)
- **VPN+FX**: estimated FX margin when booking in native currency on a regional site

## Why this exists

Built as part of doctoral research in business administration (DBA) at GlobalNxt University. The tool serves dual purpose: a working decision-framework prototype for research on enterprise pricing architecture, and a practical utility for the author’s own travel planning across APAC and Europe.

## Setup

See <SETUP.md>. ~10 minutes from zero to a live URL with weekly auto-refresh.

Required GitHub repo secret: `TRAVELPAYOUTS_TOKEN` (free signup at travelpayouts.com).

## Files

- `index.html` — single-file web app (no build step, no framework dependencies beyond CDN-loaded D3)
- `fetch_snapshot.py` — Python stdlib script that builds the JSON snapshot from the Travelpayouts API
- `.github/workflows/refresh.yml` — weekly Tuesday 06:00 UTC automation
- `flight-data.json` — auto-generated by the Action
- `SETUP.md` — deployment guide

## Tech

- D3.js v7 for the map projection (Natural Earth)
- TopoJSON v3 with world-atlas country boundaries
- Pure vanilla JS, IIFE-wrapped, ES5-compatible
- ~110 KB single file, ~2 seconds to interactive on broadband
- No cookies, no tracking, no personal data collected

## Affiliate

The tool supports optional Travelpayouts affiliate integration. To activate, edit `index.html` and paste your Travelpayouts marker ID into the `CFG.marker` variable near the top of the script. While inactive, no affiliate links or disclosures render. While active, an “Open in Aviasales →” button appears in detail panels with a footer disclosure and FTC-style `rel="sponsored"` link semantics. Affiliate-monetized booking paths surface only when the corresponding strategy is the route’s best-scoring option — editorial integrity takes precedence over monetization.
